# Cypress Project

## 📋 Overview
This repository contains end-to-end tests built with [Cypress](https://www.cypress.io/).  
Follow the instructions below to set up the project locally and execute tests from the command line.

---

### Getting Started

### 1. Clone the repository
bash
git clone https://github.com/HSMA0808/APAP-TestAutomation.git
cd <APAP-TestAutomation>

### 2. Install dependencies
npm install

### 3. Run Tests
npm run apap

### 4. Project structure
<your-repo>/
├── cypress/
│   ├── e2e/          # Test specifications
│   ├── fixtures/     # Test data
│   ├── pages/        # Objects models
│   ├── support/      # Custom commands & setup
├── cypress.config.js # Cypress configuration
├── package.json
└── readme.md
