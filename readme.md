# Playwright Project

## 📋 Overview
This repository contains end-to-end tests built with [Playwright](https://playwright.dev/).  
Follow the instructions below to set up the project locally and execute tests from the command line.

---

### Getting Started

### 1. Clone the repository
bash
git clone https://github.com/HSMA0808/APAP-TestAutomation.git

### 2. Install dependencies
npm install

### 3. Run Tests
npm run regression / npm run smoke

### 4. Project structure
APAP-TestAutomation
├── tests/               # Test specifications
├── pages/               # Object models
├── playwright.config.ts # Playwright configuration
├── package.json
└── README.md
